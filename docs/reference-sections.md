# Skills and experience reference

Skills rows, corner headings, horizontal project cards and the company timeline adapt the visual patterns of https://manixh.vercel.app/ and its MIT-licensed specification repository: https://github.com/ig-imanish/manixh. The reference copyright and license are retained in licenses/manixh-MIT.txt.

The existing portfolio skill lists, employment dates, locations, roles and achievements are preserved. The prior expandable achievement panels and teal metric highlights remain. Skills pause on hover or keyboard focus, support mouse dragging and native touch scrolling, and stop animating for reduced motion.

Company icon assets were retrieved from the employers' sites:

- Piovation: https://www.piovation.com/favicon-96x96.png
- Electronicx: https://electronicx.de/favicon.ico
- AptiDude: https://aptidude.in/apple-touch-icon.png

These company marks identify the employers and are not covered by the reference project's MIT license.

Project cards reuse existing cover images, descriptions and technology lists. Desktop uses a 300px image beside the details; at 700px and below cards stack vertically. Live and valid GitHub links remain external, while the banner, title and Read project link retain internal detail navigation. Placeholder your-username repository links are not rendered. No sponsor or usage statistics are fabricated.
