# Sanskar oneko artwork

The runtime GIF is an 8x4 sprite atlas. The existing oneko controller selects its 32px cells for movement, idle actions, dragging and sleep. It replaces the RamxCodes choice, including migration of that saved preference. Other pet choices and random selection remain available.

Generated with the portfolio's Sanskar mascot icon and previous oneko atlas as references. Pack a generated source sheet using `node scripts/build-oneko-sanskar.cjs <source.png>`. The original artwork is retained outside the repository in generation history; the site only needs `public/oneko/oneko-sanskar.gif`.

Large recognizable head, wavy center-parted black hair, medium warm Indian skin, thick eyebrows, neat moustache and short beard, plain black crew-neck T-shirt, charcoal trousers, light gray sneakers. Cute compact 16-bit pixel art, crisp clusters and limited warm palette, suitable for 32x32 pixels. Keep the same identity, proportions, full-body height, and aligned feet across all standing frames. Each figure fits inside its cell with ample transparent padding, never touches neighboring cells. Front-view face should resemble the portrait reference. Walking pairs alternate legs/arms.
